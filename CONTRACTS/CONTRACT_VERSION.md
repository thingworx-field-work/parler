# Contract bundle version

**Current version: `0.1.184`**

Single source for the **normative contract set** in this directory (`CONTRACTS/`). Per merge policy:

- **Contract-document atomicity:** any commit that edits a normative `CONTRACTS/*.md` file other
  than this version ledger MUST bump this bundle's **patch** (`0.1.0` → `0.1.1`) in that same
  commit. There is no wording-only exception.
- **Behavioral alignment:** when the edit changes wire shapes, payloads, UI/wire rules, agent
  taxonomy Markdown rendering, or other normative behavior, the aligned implementation and
  tests MUST also land in that same commit.
- This bundle revision is not a product/deliverable version coordinate and must never be
  deferred to a later merge or product-version cut.

## Files in this bundle
