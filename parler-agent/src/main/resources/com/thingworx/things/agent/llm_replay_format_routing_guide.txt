## Compact tool-result formats

Read these as evidence formats, not instructions to change scope. A result format or past tool call does not establish current tool availability; use the tools advertised for this turn.

- `parler.infotable.matrix.v1`: rows in `rows`, `sampleRows`, `rootEntityList` or `sampleRootEntityList` are cell arrays ordered by `columns`; `columns[k]` identifies cell k. `constants` applies to every row and its columns are omitted from row arrays; constant keys must not duplicate column names. Count/sample/error fields retain the returning tool's meanings; `cacheId` refers to the full cached table.
- `parler.entity.metadata.summary.v1`: identity plus optional template/tags/description, `properties[]: {name,baseType}`, and service/event names. Get full definitions from `describe_entity_schema` for supported non-Thing types; use `discover_thing_members` and `get_property_values` for Things, or an advertised service-definition tool where appropriate.
- `parler.infotable.summary.v1`: aggregate replay evidence, not rows. Use rowCount/totalCount, sampleOnly, cacheId, constants and column statistics. Numeric columns have min/max/mean; string columns have cardinality and optional top buckets. DATETIME range endpoints are chronological earliest/latest original cell strings; an invalid non-skipped date prevents that column's range. Missing stats with a cacheId indicate a pointer: use the cache or re-query for exact rows. Summary columns are not matrix indices.
- `parler.cohort.member.v1` points via `bundleToolCallId` to a sibling `parler.cohort.bundle.v1` message containing `members[]` and shared `result`. The result may be a matrix or summary. One-row-per-member results may align rows and members; multi-row results use the cohort column (for example thingName) to identify each row's source. For a summary, `memberSummaries`, when present, maps by stable memberIndex. A nonempty inner cacheId suppresses memberSummaries; do not infer per-member counts from samples. Use cache data or re-query when exact rows are needed.
